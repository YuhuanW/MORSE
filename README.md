# MORSE

Official repository for the MORSE paper on cross-sensor tactile object recognition and domain generalization.

> **Release status:** The repository is currently a public project placeholder. The source code, trained models, and dataset preparation materials are intentionally withheld during review.

## Planned release

After the paper is accepted, we will progressively release:

- the complete MORSE training and evaluation code;
- configuration files and reproducible experiment scripts;
- model checkpoints and inference examples;
- dataset indexing and preprocessing utilities;
- documentation for reproducing the reported results.

The underlying tactile datasets remain subject to their original licenses and terms of use. We will only redistribute data or derived metadata when permitted; otherwise, the release will provide download instructions and reproducible indexing scripts.

## Scope

MORSE studies local tactile evidence, evidence-bank aggregation, morphology-aware matching, relation adaptation, and optional visual context for recognition across unseen tactile sensors.
